# GitHub Trending 每日笔记

每日自动抓取 GitHub Trending Top 20，由 AI 生成中文描述，并同步到本仓库。

- 生成时间：每天 08:00（北京时间）自动执行
- 生成方式：WorkBuddy 自动化抓取 GitHub Trending，AI 生成中文摘要
- 笔记格式：按月份分目录保存，如 `2026_08/2026-08-18.md`（文件夹命名 `YYYY_MM`）

## 仓库说明

- **公开仓库**：本仓库，仅作公开同步
- **私有仓库**：`github_news_trending_days_private`，供 Obsidian 同步使用
